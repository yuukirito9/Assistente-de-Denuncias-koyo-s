# Assistente-de-Denuncias-koyo-s
um userscript visando aumentar a acessibilidade para abrir denuncias no jogo grepolis, com muitas funções e facilidades.
principalmente trazendo botao de denunciar par ao jogo, uma serie de denuncias prontas, botao de denuncia direto no grepodata.
salva o nome dos jogadores e guarda os dados de alianças e jogadores para facilitar o trabalho ao denunciar jogadores, tudo diretamente no site de suporte.
